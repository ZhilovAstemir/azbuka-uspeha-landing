# Азбука успеха — лендинг детского центра развития (Нальчик)

Одностраничный сайт на **Next.js 16 + React 19 + TypeScript + Tailwind CSS v4**
с интерактивной 3D-сценой (Three.js, шейдеры), анимациями (Framer Motion),
SEO-разметкой и подключением аналитики.

Контент заполнен по данным Instagram **@azbuka_yspeha** (выгрузка от 19.09.2026):
адрес, телефон, направления, продлёнка, акция −20%, два преподавателя, фото.

## Быстрый старт

```bash
npm install       # установить зависимости
npm run dev       # локально: http://localhost:3000
npm run build     # production-сборка
npm run start     # запустить собранную версию
```

## Где менять контент

Весь текст, направления, педагоги, отзывы, форматы, FAQ и контакты — в одном файле:

> **`src/lib/content.ts`**

```

├─ app/
│  ├─ layout.tsx        # шрифты, SEO-метаданные, JSON-LD (ChildCare + адрес в Нальчике), аналитика

│  ├─ globals.css       # дизайн-система
│  ├─ icon.jpg          # favicon (логотип центра)
│  ├─ robots.ts / sitemap.ts
├─ components/
│  ├─ Hero3D.tsx        # интерактивная 3D-сцена (курсор + скролл)
│  ├─ Header.tsx, LeadForm.tsx, TiltCard.tsx, Analytics.tsx …
│  └─ sections/         # Hero, Programs (с продлёнкой), About, Teachers, Reviews,
│                       # Prices (форматы), InstagramFeed, Faq, Contacts, Footer
├─ lib/content.ts       # ← ВЕСЬ РЕДАКТИРУЕМЫЙ КОНТЕНТ
public/
├─ images/              # фото из Instagram (12 файлов) + аватар-логотип
└─ og-image.jpg         # картинка для соцсетей 1200×630
```

## Аналитика

`src/lib/content.ts` → `site.analytics`:

```ts
analytics: {
  yandexMetrikaId: "12345678",     // номер счётчика Яндекс.Метрики
  gaMeasurementId: "G-XXXXXXXXXX", // ID Google Analytics 4
}
```

При отправке формы уходит цель `lead` в Метрику и событие `generate_lead` в GA4.

## Деплой

Без изменений разворачивается на **Vercel** (рекомендуется для Next.js) или на любом
хостинге с Node.js: `npm run build && npm run start`.

## 3D и интерактив

- Шейдерная «живая» сфера в hero: реагирует на курсор, при скролле камера отъезжает,
  сфера вращается и меняет цвет, частицы разлетаются.
- Рендер идёт только пока герой на экране; на мобильных ниже детализация.
- Уважает `prefers-reduced-motion`.
